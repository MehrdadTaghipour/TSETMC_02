# مستندات API سرور بورس تهران (TSETMC Unified API)

تمامی نقاط انتهایی سرور، پاسخی یکپارچه همراه با متادیتا (`_meta`) ارائه می‌دهند تا فرانت‌اند بتواند وضعیت دقیق اتصال، کش، وضعیت بازار و داده‌های نمایشی (Demo/Fixtures) را به درستی تشخیص داده و به کاربر نمایش دهد.

---

## ۱. ساختار متادیتای پاسخ (`_meta`)

تمامی پاسخ‌ها دارای فیلد `_meta` زیر هستند:
```json
{
  "_meta": {
    "demo": false,
    "source": "tsetmc",
    "fetched_at": "2026-10-25T08:45:00.000Z",
    "fetched_at_jalali": "1405/08/03 12:15:00",
    "cached": true,
    "stale": false,
    "market_status": "OPEN",
    "circuit_breaker": "CLOSED",
    "response_time_ms": 42
  },
  "data": { ... }
}
```

- `demo`: مقدار `true` اگر سرور به دلیل محدودیت آی‌پی یا درخواست کاربر از داده‌های پیش‌فرض تست (Fixtures) استفاده کرده باشد.
- `source`: منبع داده؛ یکی از مقادیر `"tsetmc"` (مستقیم)، `"relay"` (سرور واسط داخل ایران)، یا `"fixture"` (داده آزمایشی).
- `market_status`: یکی از مقادیر `"OPEN"` (ساعات معاملاتی)، `"PRE_OPEN"` (پیش‌گشایش)، یا `"CLOSED"` (بازار بسته است).
- `stale`: اگر سرویس به دلیل خطای بالادستی از داده کش قدیمی استفاده کرده باشد.

## ۲. فهرست نقاط انتهایی (Endpoints)

### ۲.۱ دیده‌بان بازار (Market Watch)
- **مسیر**: `GET /api/market-watch`
- **پارامترها**:
  - `sector`: کد صنعت (اختیاری)
  - `market`: کد بازار (۰: همه، ۱: بورس، ۲: فرابورس)
  - `limit`: سقف تعداد نمادها (پیش‌فرض: همه)
- **خروجی**: آرایه‌ای از خلاصه نمادها شامل آخرین قیمت (ریال و تومان)، درصد تغییر، حجم معاملات، ارزش معاملات و وضعیت نماد.

### ۲.۲ جزئیات کامل نماد (Symbol Detail)
- **مسیر**: `GET /api/symbol/{ins_code}`
- **خروجی**: کلیه مشخصات نماد شامل قیمت پایانی، آخرین معامله، بازه روز، سقف و کف مجاز، حجم مبنا، سهام شناور، EPS و P/E.

### ۲.۳ دفتر سفارشات عمق بازار (Order Book Depth)
- **مسیر**: `GET /api/symbol/{ins_code}/orderbook`
- **خروجی**: ۵ ردیف بهترین مظنه‌های خرید و فروش شامل تعداد سفارشات، حجم و قیمت.

### ۲.۴ جریان نقدینگی حقیقی و حقوقی (Client Type Flow)
- **مسیر**: `GET /api/symbol/{ins_code}/client-type`
- **خروجی**: تفکیک حجم و تعداد خریداران و فروشندگان حقیقی و حقوقی + محاسبه خالص ورود/خروج پول حقیقی (Net Real Inflow).

### ۲.۵ سابقه روزانه قیمت (Daily History)
- **مسیر**: `GET /api/symbol/{ins_code}/history?days=30`
- **خروجی**: آرایه تاریخی شامل قیمت اولین، کمترین، بیشترین، پایانی، حجم و تاریخ شمسی و میلادی.

### ۲.۶ شاخص‌های کلی (Indices)
- **مسیر**: `GET /api/indices`
- **خروجی**: اطلاعات شاخص کل، شاخص هم‌وزن، شاخص فرابورس و برترین نمادهای اثرگذار بر شاخص.

### ۲.۷ گروه‌های صنعت (Sectors)
- **مسیر**: `GET /api/sectors`
- **خروجی**: تجمیع ارزش معاملات، حجم و میانگین بازدهی صنایع برتر (فلزات اساسی، شیمیایی، خودرو، بانک‌ها و ...).

### ۲.۸ نمادهای پربازدید (Most Viewed)
- **مسیر**: `GET /api/most-viewed`
- **خروجی**: ۱۰ نماد پربیننده بازار همراه با وضعیت و تغییرات قیمتی.

### ۲.۹ جستجوی نمادها (Search / Autocomplete)
- **مسیر**: `GET /api/search?q={query}`
- **خروجی**: جستجوی آنی در نماد، نام شرکت و صنعت.

### ۲.۱۰ پایش سلامت و وضعیت ارتباط (Health & Connectivity)
- **مسیر**: `GET /api/health`
- **خروجی**: وضعیت اتصال به TSETMC، آی‌پی سرور (ایران یا خارجی)، وضعیت رله، تعداد خطاهای اخیر، وضعیت مدارشکن و فواصل زمانی پولینگ.
